# String Inspector

## Problem

This program counts vowels, digits, and spaces in a string and prints it backwards.

## Design

I used functions and loops to check each character.

## Compile and Run

`gcc q3_string_inspector.c -o string_inspector`

`./string_inspector`

## Testing

I tested it with letters, numbers, and spaces.

## Bug Fixed

I made sure the newline from `fgets()` was not counted.
